# 2026年5月22日 学習ログ

今日は TypeScript の以下の内容を学習した。

- 関数の戻り値の型

- コールバック関数
- unknown 型
- never 型

特に、"返す（return）" と "表示する（console.log）" の違いをはっきり区別できるようになった。

---

## 1. 関数の戻り値の型

関数には、引数の型だけでなく戻り値の型も指定できる。

```ts
function add(n1: number, n2: number): number {
  return n1 + n2;
}
```

この関数は `number` を2つ受け取り、`number` を返す。

一方で、値を返さず表示だけする関数は `void` になる。

```ts
function printResult(num: number): void {
  console.log("Result:" + num);
}
```

### 理解したこと

- `void` は「何もしない」ではない
- `void` は「戻り値として使える値を返さない」という意味

---

## 2. return と console.log の違い

`return` は呼び出し元に値を返す。
`console.log` はコンソールに表示するだけ。

```ts
function printResult(num: number): void {
  console.log(num);
}

printResult(10);
console.log("次の処理");
```

この場合の表示は次のとおり。

```txt
10
次の処理
```

`printResult(10)` が2つの値を返しているわけではなく、
1行目で `10` を表示したあと、次の `console.log("次の処理")` が実行されているだけ。

## 3. 関数そのものに型をつける

関数を代入する変数にも型を指定できる。

```ts
let combineValues: (a: number, b: number) => number;
```

これは「`number` を2つ受け取り、`number` を返す関数だけを代入できる」という意味。

```ts
function add(n1: number, n2: number): number {
  return n1 + n2;
}

function printResult(num: number): void {
  console.log(num);
}

combineValues = add; // OK
// combineValues = printResult; // NG
// combineValues = 5; // NG
```

## 4. コールバック関数

コールバック関数は「関数に渡す関数」。

```ts
function addAndHandle(n1: number, n2: number, cb: (num: number) => void) {
  const result = n1 + n2;
  cb(result);
  return result;
}

addAndHandle(10, 20, (result) => {
  console.log(result);
});
```

実行の流れ:

1. `10 + 20` を計算する
2. `result` が `30` になる
3. `cb(result)` が実行される
4. `console.log(30)` が実行される

表示結果:

```txt
30
```

React の `onClick={handleClick}` や、子コンポーネントから親の関数を呼ぶ処理にもつながる考え方。

## 5. callback の void と boolean

```ts
function sendRequest(data: string, cb: (response: any) => void) {
  return cb({ data: "Hi there!" });
}

sendRequest("Send this!", (response) => {
  console.log(response);
  return true;
});
```

この場合、表示されるのは次だけ。

```txt
{ data: "Hi there!" }
```

`return true;` は書けるが、コールバックの戻り値は `void` 扱いなので、呼び出し側でその値を使う前提にはしない。

戻り値として `true / false` を使いたい場合は、型を `boolean` にする。

```ts
function sendRequest(data: string, cb: (response: any) => boolean) {
  return cb({ data: "Hi there!" });
}
```

## 6. unknown 型

`unknown` は「何が入るか分からない型」。

```ts
let userInput: unknown;
let userName: string;

userInput = 5;
userInput = "Max";

// userName = userInput; // エラー
```

`unknown` はそのまま他の具体的な型に代入できない。
使う前に型チェックが必要。

```ts
if (typeof userInput === "string") {
  userName = userInput;
}
```

### 理解したこと

- `any` と違って安全側に倒れる
- 使う前に確認が必要なので、`any` より安全

---

## 7. never 型

`never` は「正常に最後まで終わらない関数」の型。

```ts
function generateError(message: string, code: number): never {
  throw { message: message, errorCode: code };
}

const result = generateError("エラーが発生しました", 500);
console.log(result);
```

このコードでは `throw` で処理が止まるため、`console.log(result)` には到達しない。

### void と never の違い

- `void`: 戻り値はないが、処理は普通に終わって次に進む
- `never`: 関数が正常に終わらず、次に進まない

---

## 今日の理解ポイント

- 戻り値とは、基本的に `return` で呼び出し元に返す値
- `console.log` は値を返しているのではなく、表示しているだけ
- `void` は戻り値として使える値を返さない関数
- `never` は正常に処理が終わらない関数
- 関数そのものにも型を指定できる
- コールバック関数は「関数に渡す関数」
- `unknown` は使う前に型チェックが必要
- `any` より `unknown` の方が安全

## 感想

今日は `return`、`console.log`、`void`、`never` の違いが特に重要だった。

`void` は「何も起きない」ではなく、
「戻り値として使える値を返さないだけで、処理自体は普通に実行される」という点を理解できた。

また、`never` はエラーや無限ループのように、関数が正常に戻ってこない場合に使う型だと分かった。

関数の型やコールバックは、React の props で関数を渡す処理や `onClick` に直結するので、今後も意識して学習していきたい。

今日の山場は、**「返す」と「表示する」は別** という理解だった。
ここを掴めると、関数・コールバック・React のイベント処理がかなり読みやすくなる。
