## 3. コードを1行ずつ説明する枠

```ts
const button = document.querySelector("button");

if (button) {
  button.addEventListener("click", (event) => {
    console.log(event);
  });
}

const add = (a: number = 5, b: number = 1) => a + b;

const activeHobbies = ["Hiking", ...hobbies];
const copiedPerson = { ...person };
```

- `document.querySelector("button")`: ボタン要素を取得する。見つからない場合は `null` になる。
- `if (button)`: `null` の可能性を消してからイベントを登録する。
- `addEventListener`: クリック時に処理を実行する。
- `(event) => { ... }`: イベントオブジェクトを受け取るアロー関数。
- `const add = (a: number = 5, b: number = 1) => a + b;`: デフォルト引数つきの短い関数。
- `...hobbies`: 配列の中身を展開して別の配列に入れる。
- `...person`: オブジェクトの中身をコピーする。

## 4. テンプレートに取り込める学びの枠

- 命名ルール: `const` を基本にして、再代入するものだけ `let` を使う。
- データ更新ルール: 配列やオブジェクトはスプレッド構文でコピーしてから更新する。
- API設計ルール: `querySelector` などは `null` の可能性を前提に扱う。
- エラー処理ルール: `noImplicitReturns` や `noUnusedLocals` を使うと、学習段階でもミスに気づきやすい。

## 6. つまずきと対策の枠

- つまずいたこと: `app.ts` が実行されないように見えた。
- 原因: `src` 外のファイルを編集していたことと、別ファイルの TypeScript エラーで `noEmitOnError` が働いていたこと。
- 対策: `src` 配下に置き、全ファイルのエラーをなくしてから `tsc -w` を動かす。
- 次回の予防: 実行前に「編集したファイルが tsconfig の include に入っているか」を確認する。
