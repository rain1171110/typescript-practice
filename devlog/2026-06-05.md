## 1. オブジェクト指向とは

オブジェクト指向とは、**データと処理をセットにして考える書き方**。

たとえば `Department` なら、

```text
name
employees
addEmployee()
describe()
printEmployeeInformation()
```

のように、部門に関係する情報と処理を1つにまとめる考え方。

---

## 2. class とは何か

`class` は、**オブジェクトを作るための設計図**。

```ts
class Department {
  name: string;
}
```

これはまだ実物ではなく、`new` することで実際のオブジェクトが作られる。

```ts
const accounting = new Department("Accounting");
```

---

## 3. constructor とは何か

`constructor` は、**new した瞬間に自動で動く初期設定の関数**。

```ts
constructor(n: string) {
  this.name = n;
}
```

`new Department("Accounting")` とすると、`"Accounting"` が `n` に入り、`this.name` にセットされる。

---

## 4. this は何を指すのか

`this` は基本的に、**そのメソッドを呼び出している左側のオブジェクト**を指す。

```ts
accounting.addEmployee("Max");
```

この場合、`this` は `accounting`。

だから、

```ts
this.employees.push(employee);
```

は、

```text
accounting の employees に employee を追加する
```

という意味になる。

---

## 5. public / private / protected の違い

`public` は外からも class 内からも子 class からも触れる。

`private` はその class の中だけで触れる。外からも子 class からも触れない。

`protected` は外からは触れないが、自分の class と子 class からは触れる。

整理すると、

```text
public    → 外から触れる
private   → 自分の class の中だけ
protected → 自分の class と子 class の中だけ
```

`employees` を `private` や `protected` にする理由は、外から勝手に変更させず、`addEmployee()` のような決めたメソッドを通して操作させるため。

---

## 6. readonly の意味

`readonly` は、**最初に設定したらあとから変更できない**という意味。

```ts
constructor(
  protected readonly id: string,
  public name: string
) {}
```

`id` は部門番号のようなものなので、あとから変更できないようにする。

---

## 7. 継承 extends / super

`extends` は、**親 class の機能を子 class が引き継ぐ**こと。

```ts
class ITDepartment extends Department {}
```

これで `ITDepartment` は `Department` の機能を使える。

`super()` は、**親 class の constructor を呼ぶ**もの。

```ts
constructor(id: string, admins: string[]) {
  super(id, "IT");
  this.admins = admins;
}
```

`super(id, "IT")` によって、親の `Department` に `id` と `name` を渡して初期設定している。

---

## 8. static

`static` は、**インスタンスではなく class 自体に属するもの**。

```ts
static fiscalYear = 2020;

static createEmployee(name: string) {
  return { name: name };
}
```

使うときは、作ったオブジェクトからではなく class 名から使う。

```ts
Department.fiscalYear;
Department.createEmployee("Max");
```

`this.fiscalYear` ではなく、`Department.fiscalYear` と書くのがポイント。

---

## 9. abstract class / abstract method

`abstract class` は、**直接 new できない親専用の class**。

```ts
abstract class Department {}
```

これにより、

```ts
new Department(...)
```

はできない。

`abstract method` は、**子 class に必ず実装させるメソッド**。

```ts
abstract describe(this: Department): void;
```

親 class では中身を書かず、子 class 側で必ず書く。

```ts
describe() {
  console.log("IT部門 - ID: " + this.id);
}
```

つまり、`Department` を継承するなら、`describe()` は必ず自分で作らないといけない。

## 今日の理解ポイント

今日一番大事だったのは、これ。

```text
this = メソッドを呼び出している左側のオブジェクト
```

たとえば、

```ts
it.addEmployee("Max");
```

なら、`this` は `it`。

```ts
accounting.printEmployeeInformation();
```

なら、`this` は `accounting`。

ここが class 理解の中心。
