## 1. singleton の復習

singleton は、

> **クラスから作れるオブジェクトを1個だけに制限する仕組み**

だと理解した。

通常の class は `new` を使えば何個でもオブジェクトを作れる。

```ts
const accounting1 = new AccountingDepartment("d1", []);
const accounting2 = new AccountingDepartment("d2", []);
```

しかし singleton では、外から自由に `new` できないようにして、
`getInstance()` を通して1個だけ使い回す。

```ts
const accounting1 = AccountingDepartment.getInstance();
const accounting2 = AccountingDepartment.getInstance();

console.log(accounting1 === accounting2); // true
```

---

## 2. singleton の重要ポイント

singleton の中心はこの3つ。

```ts
private constructor
```

外から勝手に `new` できないようにする。

```ts
private static instance: AccountingDepartment;
```

作った1個のオブジェクトを保存しておく場所。

```ts
static getInstance()
```

まだオブジェクトがなければ作る。
すでにあれば、保存してある同じオブジェクトを返す。

---

## 3. getInstance() の流れ

```ts
static getInstance() {
  if (this.instance) {
    return this.instance;
  }

  this.instance = new AccountingDepartment("d2", []);
  return this.instance;
}
```

最初に呼んだときは、まだ `instance` がないので、

```ts
this.instance = new AccountingDepartment("d2", []);
```

で新しく作る。

2回目以降は、

```ts
if (this.instance) {
  return this.instance;
}
```

で、すでにある同じオブジェクトを返す。

つまり singleton は、

> **1回目だけ作る。2回目以降は同じものを返す。**

という仕組み。

---

## 4. singleton 理解チェック

問題を解いて、10問中8問正解した。

間違えたポイントは、

```ts
const accounting1 = AccountingDepartment.getInstance();
const accounting2 = AccountingDepartment.getInstance();
```

これは2個作られるのではなく、
**1回目だけ作られて、2回目は同じものが返る** という点。

また、

```ts
this.instance = new AccountingDepartment("d2", []);
```

が実行されるのは、
**まだ instance がないとき** だと理解した。

## 5. interface の学習

次に TypeScript の `interface` について学習した。

```ts
interface Person {
  name: string;
  age: number;

  greet(phrase: string): void;
}
```

これは、

> Person 型のオブジェクトは、
> `name`、`age`、`greet()` を必ず持つ

というルール。

interface は class のようにオブジェクトを作るものではなく、
**オブジェクトの形を決める約束** だと理解した。

---

## 6. Person 型のオブジェクト

```ts
let user1: Person;

user1 = {
  name: "Max",
  age: 30,
  greet(phrase: string) {
    console.log(phrase + " " + this.name);
  },
};
```

`user1` は `Person` 型なので、
`name`、`age`、`greet()` を持つ必要がある。

このオブジェクトはその条件を満たしているのでOK。

---

## 7. greet() の呼び出し

```ts
user1.greet("Hello I am");
```

これを実行すると、`greet` の中の

```ts
console.log(phrase + " " + this.name);
```

が動く。

このとき、

```txt
phrase = "Hello I am"
this.name = user1.name = "Max"
```

なので、出力はこうなる。

```txt
Hello I am Max
```

---

## 8. TS6133 エラーについて

最初に、

```txt
'user1' is declared but its value is never read.
```

というエラーが出た。

これは、

> `user1` を宣言したけど、どこでも使っていない

という意味。

しかし最後に、

```ts
user1.greet("Hello I am");
```

と書くことで、`user1` を実際に使っているため、このエラーは消える。
