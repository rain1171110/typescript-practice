# 2026-06-12 学習ログ

## 今日のテーマ

TypeScript の型ガードの中でも重要な、**判別可能な Union 型**について復習した。

今回は `Bird` と `Horse` のような複数の型を、共通の `type` プロパティを使って安全に分ける書き方を確認した。

## 学習内容

`Animal` 型を `Bird | Horse` の Union 型として定義した。

```ts
interface Bird {
  type: "鳥";
  flyingSpeed: number;
}

interface Horse {
  type: "馬";
  runningSpeed: number;
}

type Animal = Bird | Horse;
```

ここで重要なのは、`type` をただの `string` にするのではなく、`"鳥"` や `"馬"` のような**決まった文字列リテラル型**にしていること。

```ts
type: "鳥";
type: "馬";
```

この `type` プロパティが、型を判別するための「名札」の役割をしている。

## 実際に書いたコード

```ts
interface Bird {
  type: "鳥";
  flyingSpeed: number;
}

interface Horse {
  type: "馬";
  runningSpeed: number;
}

type Animal = Bird | Horse;

function moveAnimal(animal: Animal) {
  let speed: number;

  switch (animal.type) {
    case "鳥":
      speed = animal.flyingSpeed;
      break;

    case "馬":
      speed = animal.runningSpeed;
      break;
  }

  console.log(`${animal.type}の移動速度:` + speed);
}

moveAnimal({ type: "鳥", flyingSpeed: 10 });
moveAnimal({ type: "馬", runningSpeed: 20 });
```

## 理解したこと

`Animal` は `Bird` または `Horse` のどちらかの型になる。

そのため、何も判定せずにいきなり `animal.flyingSpeed` や `animal.runningSpeed` を使うと危険になる。

そこで、`switch (animal.type)` を使って、`type` の値を確認する。

```ts
switch (animal.type)
```

`case "鳥"` の中では、TypeScript が `animal` は `Bird` だと判断してくれる。

そのため、以下のように `flyingSpeed` を安全に使える。

```ts
speed = animal.flyingSpeed;
```

反対に、`case "馬"` の中では、TypeScript が `animal` は `Horse` だと判断してくれる。

そのため、以下のように `runningSpeed` を安全に使える。

```ts
speed = animal.runningSpeed;
```

## 今日のポイント

判別可能な Union 型では、共通のプロパティを使って型を分ける。

今回の場合は、`type` プロパティが共通の目印になっている。

```ts
type: "鳥";
type: "馬";
```

このように決まった値を持たせることで、TypeScript が型を安全に絞り込んでくれる。

日本語の `"鳥"` や `"馬"` でも問題なく使えることも確認できた。

## 改善ポイント

最初は `let speed;` と書いていたが、TypeScript では型を明確にするために次のように書くとよい。

```ts
let speed: number;
```

また、最後の `case` にも `break;` を書いておくと、あとから型が増えたときにもミスを防ぎやすい。

## まとめ

今日は、判別可能な Union 型について復習した。

`Bird | Horse` のような Union 型では、共通の `type` プロパティを使うことで、TypeScript が自動的に型を判断してくれる。

`type: "鳥"` の場合は `Bird`、`type: "馬"` の場合は `Horse` として扱えるため、それぞれの型にしか存在しないプロパティも安全に使える。

型ガードの中でもかなり重要な考え方なので、今後 Union 型を使うときは、共通の目印プロパティを作ることを意識したい。
