## 学習内容

### 1. `extends object` による制約

```ts
function merge<T extends object, U extends object>(objA: T, objB: U) {
  return Object.assign(objA, objB);
}

const mergedObj = merge({ name: "Max", hobbies: ["Sports"] }, { age: 30 });

console.log(mergedObj.name);
console.log(mergedObj);
```

`T extends object` と書くことで、ジェネリクスに入る型をオブジェクトだけに制限できる。
これにより、`string` や `number` のような値を誤って渡すことを防げる。

また、ジェネリクスを使うことで、戻り値にも元の型情報が残る。
そのため、`mergedObj.name` のように安全にプロパティへアクセスできる。

### 2. `length` を持つ型だけを受け取る

```ts
interface Lengthy {
  length: number;
}

function countAndDescribe<T extends Lengthy>(element: T): [T, string] {
  let descriptionText = "値がありません";

  if (element.length > 0) {
    descriptionText = "値は" + element.length + "個です。";
  }

  return [element, descriptionText];
}

console.log(countAndDescribe(["Sports", "Cooking"]));
```

`T extends Lengthy` とすることで、`length` プロパティを持つ値だけを受け取れるようにした。

文字列や配列は `length` を持っているため使える。
しかし、`number` は数値そのものであり、「中に何個あるか」を表すデータではないため `length` は使えない。

```ts
"Hello".length;
// 5

["A", "B", "C"].length;
// 3

// 10.length;
// エラー
```

### 3. `keyof` を使って存在するキーだけを指定する

```ts
function extractAndConvert<T extends object, U extends keyof T>(
  obj: T,
  key: U,
) {
  return "Value: " + obj[key];
}

console.log(extractAndConvert({ name: "Max" }, "name"));
```

`U extends keyof T` は、`U` を `T` に存在するキーだけに制限する書き方。

たとえば `{ name: "Max" }` のキーは `"name"` なので、第二引数には `"name"` だけ渡せる。

```ts
extractAndConvert({ name: "Max" }, "name");
// OK

// extractAndConvert({ name: "Max" }, "age");
// エラー
```

存在しないキーを指定できないので、安全にオブジェクトの値を取り出せる。

### 4. ジェネリッククラス

```ts
class DataStorage<T extends string | number | boolean> {
  private data: T[] = [];

  addItem(item: T) {
    this.data.push(item);
  }

  removeItem(item: T) {
    if (this.data.indexOf(item) === -1) {
      return;
    }
    this.data.splice(this.data.indexOf(item), 1);
  }

  getItems() {
    return [...this.data];
  }
}

const textStorage = new DataStorage<string>();
textStorage.addItem("Data1");
textStorage.addItem("Data2");
textStorage.removeItem("Data1");
console.log(textStorage.getItems());

const numberStorage = new DataStorage<number>();
numberStorage.addItem(30);
numberStorage.removeItem(30);
numberStorage.addItem(40);
console.log(numberStorage.getItems());
```

`DataStorage` は、保存するデータの型をあとから指定できるクラス。

```ts
const textStorage = new DataStorage<string>();
```

と書くと、文字列専用の保管箱になる。

```ts
const numberStorage = new DataStorage<number>();
```

と書くと、数値専用の保管箱になる。

今回は、

```ts
T extends string | number | boolean
```

と制限することで、`indexOf()` で比較しやすいプリミティブ型だけを扱うようにした。

オブジェクトは中身が同じでも別物として扱われるため、`indexOf()` で削除するときに注意が必要。

```ts
{ name: "Max" } === { name: "Max" };
// false
```

### 5. パラメーター・引数・戻り値の整理

```ts
function add(a: number, b: number): number {
  return a + b;
}

add(2, 5);
```

- `a`, `b` はパラメーター
- `2`, `5` は引数
- `a + b` は戻り値

覚え方：

```ts
function 関数名(パラメーター) {
  return 戻り値;
}

関数名(引数);
```

作るときに書く受け取り口がパラメーター。
使うときに渡す値が引数。
処理のあとに返ってくる結果が戻り値。

### 6. `Partial`

```ts
interface CourseGoal {
  title: string;
  description: string;
  completeUntil: Date;
}

function createCourseGoal(
  title: string,
  description: string,
  date: Date,
): CourseGoal {
  let courseGoal: Partial<CourseGoal> = {};

  courseGoal.title = title;
  courseGoal.description = description;
  courseGoal.completeUntil = date;

  return courseGoal as CourseGoal;
}
```

`Partial` は、`CourseGoal` の全プロパティを一時的に optional にする型。

本来 `CourseGoal` は以下の3つが必須。

```ts
interface CourseGoal {
  title: string;
  description: string;
  completeUntil: Date;
}
```

しかし、`Partial` にすると次のような状態になる。

```ts
{
  title?: string;
  description?: string;
  completeUntil?: Date;
}
```

そのため、最初に空オブジェクト `{}` を作って、あとから値を追加できる。

### 7. `Readonly`

```ts
const names: Readonly<string[]> = ["Max", "Anna"];

// names.push("Manu");
// names[0] = "Manu";
```

`Readonly` は、配列を読み取り専用にする型。

`const` は変数の再代入を禁止するだけだが、配列の中身は変更できる。

```ts
const names = ["Max", "Anna"];
names.push("Manu");
// OK
```

しかし、`Readonly` を使うと、配列の中身の変更も禁止できる。

```ts
const names: Readonly<string[]> = ["Max", "Anna"];

// names.push("Manu");
// エラー
```

## 今日覚えた Utility Type

```ts
Partial; // 全部 optional にする
Required; // 全部 必須にする
Readonly; // 変更できないようにする
Pick; // 必要なプロパティだけ選ぶ
Omit; // 指定したプロパティだけ除外する
Record; // キーと値の型を指定してオブジェクト型を作る
Exclude; // Union 型から一部を除外する
Extract; // Union 型から一致するものだけ取り出す
NonNullable; // null / undefined を除外する
ReturnType; // 関数の戻り値の型を取り出す
Parameters; // 関数の引数の型を取り出す
```

## 今日の理解ポイント

ジェネリクスは、型を固定せずに使い回せる仕組み。
ただし、何でも受け取れるようにすると危険な場合がある。

そのため、

```ts
T extends object
T extends Lengthy
U extends keyof T
T extends string | number | boolean
```

のように制約をつけることで、安全に使える範囲を決められる。

また、Utility Type を使うことで、既存の型を直接書き換えずに、用途に合わせて加工できる。
