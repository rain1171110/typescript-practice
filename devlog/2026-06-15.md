# 2026-06-15 学習ログ

## テーマ：TypeScript デコレーターとインスタンス化の理解

今日は TypeScript の **クラスデコレーター** について学習した。
特に、`@WithTemplate(...)` がすぐ下の `Person` クラスにタグ付けされ、そのクラスがデコレーター関数の `constructor` に渡される流れを確認した。

```ts
function WithTemplate(template: string, hookId: string) {
  return function (constructor: any) {
    const hookEl = document.getElementById(hookId);
    const p = new constructor();

    if (hookEl) {
      hookEl.innerHTML = template;
      hookEl.querySelector("h1")!.textContent = p.name;
    }
  };
}
```

```ts
@WithTemplate("Personオブジェクト", "app")
class Person {
  name = "Max";

  constructor() {
    console.log("Personオブジェクト作成中…");
  }
}

const pers = new Person();

console.log(pers);
```

## 今日理解したこと

`@WithTemplate("Personオブジェクト", "app")` は、普通の関数呼び出しのように見えるが、実際にはデコレーターファクトリーとして動く。

イメージとしては、次のように考える。

```ts
WithTemplate("Personオブジェクト", "app")(Person);
```

つまり、外側の `WithTemplate(...)` で `template` と `hookId` を受け取り、内側の関数に `Person` クラスそのものが渡される。

```ts
return function (constructor: any) {
```

この `constructor` には、`Person` クラスが入る。

そのため、

```ts
const p = new constructor();
```

は、実質的に次と同じ意味になる。

```ts
const p = new Person();
```

ここで重要なのは、**クラスはあくまで設計図であり、`new` したときに初めて実物のオブジェクトが作られる**ということ。

```ts
class Person {
  name = "Max";
}
```

この時点では、`name = "Max"` を持った実物はまだ存在しない。
`new Person()` して初めて、`name` を持ったインスタンスが作られる。

```ts
const p = new Person();
console.log(p.name); // "Max"
```

だから、デコレーターの中で `p.name` を使うために、

```ts
const p = new constructor();
```

でインスタンス化している。

## DOM 操作の理解

```ts
const hookEl = document.getElementById(hookId);
```

ここでは、`hookId` に `"app"` が入っているので、実際には次のように動く。

```ts
document.getElementById("app");
```

HTML 側に、

```html
<div id="app"></div>
```

があれば、この要素を取得できる。

その後、

```ts
hookEl.innerHTML = template;
```

で `Personオブジェクト` を入れ、

```ts
hookEl.querySelector("h1")!.textContent = p.name;
```

で `<h1>` の文字を `p.name`、つまり `"Max"` に書き換える。

最終的に画面には、

```
Max
```

が表示される。

## 今日の重要ポイント

```
Person クラス = 設計図
new Person() = 実物を作る
p = Person から作られたインスタンス
p.name = "Max"

constructor = Person クラスそのもの
new constructor() = new Person()
```

`constructor` という名前が出てくるが、ここでは `class Person` の中の `constructor()` メソッドそのものではなく、**Person クラス自体**を指している。

## 感想

デコレーター、クラス、インスタンス化、DOM 操作が一気に出てきてかなり難しかった。
特に `constructor` に `Person` クラスが入ること、そして `new constructor()` が `new Person()` と同じになることが混乱しやすかった。

ただ、最終的に「クラスは設計図であり、`new` して初めて実物が作られる」という考え方が少しつながった。
まだ完全にはすっきりしていないので、明日はこの `WithTemplate` のコードをもう一度復習する。
