今日理解したこと
1. <template> はそのまま画面に表示されない

HTML に以下のように書いてあっても、画面にはまだ表示されない。

<template id="project-input">
  <form>
    ...
  </form>
</template>

<template> は、画面に出ている部品ではなく、あとで使うための設計図のようなもの。

2. document.importNode(..., true) でテンプレートをコピーする
const importedInputNode = document.importNode(
  projectInputTemplate.content,
  true,
);

これは、project-input テンプレートの中身をコピーしている。

projectInputTemplate.content

でテンプレートの中身を取り出す。

true

は、中の子要素まで全部コピーするという意味。

3. appendChild で画面に追加する
app.appendChild(importedInputNode);

これは、コピーしたテンプレートの中身を、実際の画面に追加している。

今回なら、

<div id="app"></div>

の中にフォームを追加している。

4. projectListTemplate は最初に1回だけ使う
const importedListNode = document.importNode(
  projectListTemplate.content,
  true,
);

app.appendChild(importedListNode);

project-list は、プロジェクトを入れるためのリストエリア。

イメージとしては「棚」。

<section class="projects">
  <header>
    <h2></h2>
  </header>
  <ul></ul>
</section>

このリストエリアは、最初に1回だけ画面に出せばよい。

5. projectSingleTemplate は submit されるたびに使う
const importedProjectNode = document.importNode(
  projectSingleTemplate.content,
  true,
);

single-project は、プロジェクト1件分の <li>。

<template id="single-project">
  <li></li>
</template>

これは、フォームが送信されてプロジェクトが追加されるたびに、毎回新しくコピーする。

理由は、1回の submit ごとに新しい <li> を1つ作りたいから。

今日つまずいたところ

最初は、projectListTemplate と projectSingleTemplate の使うタイミングが混ざっていた。

間違いやすい考え方。

projectListTemplate を submit の中でコピーする
projectSingleTemplate を submit の外でコピーする

でも、正しくは逆。

projectListTemplate は最初に1回だけコピーする
projectSingleTemplate は submit のたびにコピーする

イメージとしては、

project-list    → 棚。最初に1回置く。
single-project  → 商品カード。追加のたびに1枚作る。
submit の中の流れ

フォーム送信時には、以下の流れで処理している。

projectForm.addEventListener("submit", (event) => {
  event.preventDefault();

  const title = titleEl.value;
  const description = descriptionEL.value;
  const manday = +mandayEL.value;

  const createdProject = new Project(title, description, manday);

  const importedProjectNode = document.importNode(
    projectSingleTemplate.content,
    true,
  );

  const projectItem = importedProjectNode.firstElementChild as HTMLElement;

  projectItem.textContent = createdProject.title;
  projectList.appendChild(projectItem);
});
