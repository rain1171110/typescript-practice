## テンプレート操作の復習

HTML の `<template>` は、最初から画面に表示されるものではなく、画面部品の「設計図」として使います。

TypeScript 側で、

```ts
document.importNode(template.content, true);
```

を使うことで、テンプレートの中身をコピーできます。

その後、

```ts
appendChild();
```

や

```ts
insertAdjacentElement();
```

を使って、コピーした要素を画面に追加します。

---

## project-list と single-project の違い

`project-list` はプロジェクト一覧を表示するための「入れ物」です。

そのため、最初に1回だけ画面に表示すればよいです。

一方で、`single-project` はプロジェクト1件分の `<li>` の設計図です。

プロジェクトが追加されるたびに新しい `<li>` が必要になるため、submit の中で毎回コピーします。

```txt
project-list
→ 一覧の入れ物なので最初に1回だけ作る

single-project
→ プロジェクト1件分なので submit のたびに毎回コピーする
```

---

## querySelector と querySelectorAll の違い

今日、途中で少し脱線しましたが、重要な復習になりました。

```ts
projectItem.querySelector("p");
```

は、最初の `<p>` だけを取得します。

そのため、2回書いても同じ最初の `<p>` を操作します。

```ts
projectItem.querySelector("p")!.textContent = createdProject.description;
projectItem.querySelector("p")!.textContent = `${createdProject.manday}人日`;
```

このように書くと、2回目も最初の `<p>` を取得するため、`description` が `manday` に上書きされてしまいます。

複数の `<p>` を別々に操作したい場合は、`querySelectorAll()` を使います。

```ts
const paragraphs = projectItem.querySelectorAll("p");

paragraphs[0]!.textContent = createdProject.description;
paragraphs[1]!.textContent = `${createdProject.manday}人日`;
```

ここでの `[0]` や `[1]` は個数ではなく、場所番号です。

```txt
paragraphs[0]
→ 1個目の p

paragraphs[1]
→ 2個目の p
```

## 自作コードで確認した流れ

submit されたときに、入力値から `Project` インスタンスを作り、バリデーションをして、問題なければ `<li>` を作って画面に追加するところまで復習しました。

```ts
interface validatorConfig {
  [prop: string]: {
    [validatableProp: string]: string[];
  };
}

const registeredValidators: validatorConfig = {};

function Required(target: any, propName: string) {
  registeredValidators[target.constructor.name] = {
    ...registeredValidators[target.constructor.name],
    [propName]: [
      ...(registeredValidators[target.constructor.name]?.[propName] ?? []),
      "required",
    ],
  };
}

function PositiveNumber(target: any, propName: string) {
  registeredValidators[target.constructor.name] = {
    ...registeredValidators[target.constructor.name],
    [propName]: [
      ...(registeredValidators[target.constructor.name]?.[propName] ?? []),
      "positive",
    ],
  };
}

function validate(obj: any) {
  const objValidatorConfig = registeredValidators[obj.constructor.name];

  if (!objValidatorConfig) {
    return true;
  }

  let isValid = true;

  for (const prop in objValidatorConfig) {
    const validators = objValidatorConfig[prop];

    if (!validators) {
      continue;
    }

    for (const validator of validators) {
      switch (validator) {
        case "required":
          isValid = isValid && !!obj[prop];
          break;
        case "positive":
          isValid = isValid && obj[prop] > 0;
          break;
      }
    }
  }

  return isValid;
}

class Project {
  @Required
  title: string;

  @Required
  description: string;

  @PositiveNumber
  manday: number;

  constructor(t: string, d: string, m: number) {
    this.title = t;
    this.description = d;
    this.manday = m;
  }
}

const projectInputTemplate = document.getElementById(
  "project-input",
) as HTMLTemplateElement;

const projectSingleTemplate = document.getElementById(
  "single-project",
) as HTMLTemplateElement;

const projectListTemplate = document.getElementById(
  "project-list",
) as HTMLTemplateElement;

const app = document.getElementById("app") as HTMLDivElement;

const importedInputNode = document.importNode(
  projectInputTemplate.content,
  true,
);

const importedListNode = document.importNode(
  projectListTemplate.content,
  true,
);

app.appendChild(importedInputNode);
app.appendChild(importedListNode);

const listTitle = document.querySelector(".projects h2")!;
listTitle.textContent = "有効なプロジェクト";

const projectList = document.querySelector(".projects ul")!;

const projectForm = document.querySelector("form")!;

projectForm.addEventListener("submit", (event) => {
  event.preventDefault();

  const titleEl = document.getElementById("title") as HTMLInputElement;
  const descriptionEl = document.getElementById(
    "description",
  ) as HTMLTextAreaElement;
  const mandayEl = document.getElementById("manday") as HTMLInputElement;

  const title = titleEl.value;
  const description = descriptionEl.value;
  const manday = +mandayEl.value;

  const createdProject = new Project(title, description, manday);

  if (!validate(createdProject)) {
    alert("正しく入力して下さい");
    return;
  }

  const importedProjectNode = document.importNode(
    projectSingleTemplate.content,
    true,
  );

  const projectItem = importedProjectNode.firstElementChild as HTMLElement;

  projectItem.querySelector("h2")!.textContent = createdProject.title;

  const paragraphs = projectItem.querySelectorAll("p");
  paragraphs[0]!.textContent = createdProject.description;
  paragraphs[1]!.textContent = `${createdProject.manday}人日`;

  projectList.appendChild(projectItem);
});
```

## validate の流れ

`validate(createdProject)` では、デコレーターで登録されたルールを見て、実際の入力値をチェックします。

```ts
const objValidatorConfig = registeredValidators[obj.constructor.name];
```

ここでは、`obj.constructor.name` によって `"Project"` を取得します。

そのため、実質的には以下のような情報を見ています。

```ts
registeredValidators["Project"];
```

中身のイメージはこうです。

```ts
{
  Project: {
    title: ["required"],
    description: ["required"],
    manday: ["positive"],
  },
}
```

`for...in` で `title` / `description` / `manday` を順番に取り出し、それぞれのバリデーションルールを確認します。

```ts
for (const prop in objValidatorConfig) {
  const validators = objValidatorConfig[prop];
}
```

ここで、

```ts
objValidatorConfig[prop]
```

はバリデーション設定を見る処理です。

一方で、

```ts
obj[prop]
```

は実際の入力値を見る処理です。

たとえば `prop = "title"` のとき、

```ts
obj[prop]
```

は、

```ts
createdProject.title
```

と同じ意味になります。

## 模範解答の開始

今日の最後に、模範解答の `ProjectInput` クラスに入りました。

模範解答では、これまで外側に直接書いていたテンプレート操作を、クラスの中にまとめています。

```ts
class ProjectInput {
  templateElement: HTMLTemplateElement;
  hostElement: HTMLDivElement;
  element: HTMLFormElement;

  constructor() {
    this.templateElement = document.getElementById(
      "project-input",
    )! as HTMLTemplateElement;

    this.hostElement = document.getElementById("app")! as HTMLDivElement;

    const importedNode = document.importNode(
      this.templateElement.content,
      true,
    );

    this.element = importedNode.firstElementChild as HTMLFormElement;

    this.attach();
  }

  private attach() {
    this.hostElement.insertAdjacentElement("afterbegin", this.element);
  }
}

const prjInput = new ProjectInput();
```

---

## ProjectInput クラスの役割

`ProjectInput` クラスは、プロジェクト入力フォームを画面に表示するためのクラスです。

```txt
ProjectInput
→ project-input テンプレートから form をコピーして、#app に表示するクラス
```

---

## 各プロパティの意味

```ts
templateElement: HTMLTemplateElement;
hostElement: HTMLDivElement;
element: HTMLFormElement;
```

それぞれの意味は以下です。

```txt
templateElement
→ <template id="project-input"> の設計図

hostElement
→ フォームを追加する場所。今回は <div id="app">

element
→ テンプレートからコピーして作った実物の form
```

特に重要なのは、`templateElement` と `element` の違いです。

```txt
templateElement
→ 設計図

element
→ 設計図からコピーして作った実物の form
```

---

## constructor の流れ

`constructor` は、`new ProjectInput()` された瞬間に自動で動きます。

```ts
const prjInput = new ProjectInput();
```

この1行によって、以下の流れが実行されます。

```txt
new ProjectInput()
↓
constructor が動く
↓
project-input テンプレートを取得
↓
app を取得
↓
template の中身を importNode でコピー
↓
firstElementChild で form を取り出す
↓
attach() を呼ぶ
↓
form を #app に表示する
```

---

## attach メソッド

```ts
private attach() {
  this.hostElement.insertAdjacentElement("afterbegin", this.element);
}
```

`attach()` は、作成したフォームを画面に追加するためのメソッドです。

`private` が付いているので、このメソッドはクラスの外から直接呼ぶものではありません。

```ts
prjInput.attach();
```

このようには呼べません。

`attach()` は、`ProjectInput` クラスの内部処理として使われます。

---

## insertAdjacentElement の意味

模範解答では、`appendChild()` ではなく、`insertAdjacentElement()` が使われています。

```ts
this.hostElement.insertAdjacentElement("afterbegin", this.element);
```

`afterbegin` は、開始タグの直後という意味です。

```html
<div id="app">
  <!-- ここに form が追加される -->
</div>
```

`appendChild()` は最後に追加するイメージですが、`insertAdjacentElement("afterbegin", ...)` は、指定した場所の中の最初に追加するイメージです。

今日は、テンプレート操作の復習から始めて、模範解答のクラス設計に入りました。

```txt
importNode

firstElementChild

private

```
