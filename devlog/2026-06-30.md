# 学習ログ：ProjectState と ProjectList の連携まで進めた

## 今日のテーマ

今日は TypeScript のプロジェクト管理アプリ課題で、フォームに入力したプロジェクトを画面に表示する流れを学習した。

前回までは、`ProjectInput` クラスでフォーム入力を取得し、バリデーションして、`console.log()` に表示するところまでだった。

今日はそこから進んで、

```ts id="j2r3sw"
ProjectInput
↓
ProjectState
↓
ProjectList
↓
画面の ul に li として表示
```

という流れを作った。

ただし、特に `ProjectState` の `listeners` と、`ProjectList` の `assignedProjects` のあたりから理解が曖昧になってきた。

次回はこのコード理解から再開する。

---

## 今日書いた中心コード

```ts id="mss8av"
// ProjectState Class
class ProjectState {
  private listeners: Function[] = [];
  private projects: any[] = [];

  addListener(listenerFn: Function) {
    this.listeners.push(listenerFn);
  }

  addProject(title: string, description: string, numOfPeople: number) {
    const newProject = {
      title: title,
      description: description,
      people: numOfPeople,
    };

    this.projects.push(newProject);

    for (const listenerFn of this.listeners) {
      listenerFn(this.projects.slice());
    }

    console.log(this.projects);
  }
}

const projectState = new ProjectState();

// ProjectList Class
class ProjectList {
  templateElement: HTMLTemplateElement;
  hostElement: HTMLDivElement;
  element: HTMLElement;
  assignedProjects: any[] = [];

  constructor(private type: "active" | "finished") {
    this.templateElement = document.getElementById(
      "project-list",
    )! as HTMLTemplateElement;

    this.hostElement = document.getElementById("app")! as HTMLDivElement;

    const importedNode = document.importNode(
      this.templateElement.content,
      true,
    );

    this.element = importedNode.firstElementChild as HTMLElement;
    this.element.id = `${this.type}-projects`;

    projectState.addListener((projects: any[]) => {
      this.assignedProjects = projects;
      this.renderProjects();
    });

    this.attach();
    this.renderContent();
  }

  private attach() {
    this.hostElement.insertAdjacentElement("beforeend", this.element);
  }

  private renderContent() {
    const listId = `${this.type}-projects-list`;
    this.element.querySelector("ul")!.id = listId;
    this.element.querySelector("h2")!.textContent =
      this.type === "active" ? "実行中プロジェクト" : "完了プロジェクト";
  }

  private renderProjects() {
    const listEl = document.getElementById(
      `${this.type}-projects-list`,
    )! as HTMLUListElement;

    listEl.innerHTML = "";

    for (const prjItem of this.assignedProjects) {
      const listItem = document.createElement("li");
      listItem.textContent = prjItem.title;
      listEl.appendChild(listItem);
    }
  }
}
```

## 今日できたこと

今日は、フォームに入力した値を `ProjectState` に保存し、それを `ProjectList` に通知して、画面に表示するところまで進んだ。

大きな流れは以下。

```ts id="ko23hv"
projectState.addProject(title, desc, people);
```

これが `ProjectInput` の `submitHandler()` から呼ばれる。

その結果、`ProjectState` の中で新しいプロジェクトが作られる。

```ts id="fusfu0"
const newProject = {
  title: title,
  description: description,
  people: numOfPeople,
};
```

そして、`projects` 配列に追加される。

```ts id="o41taa"
this.projects.push(newProject);
```

そのあと、登録されている listener に通知される。

```ts id="i4e7xd"
for (const listenerFn of this.listeners) {
  listenerFn(this.projects.slice());
}
```

通知を受け取った `ProjectList` は、受け取った配列を `assignedProjects` に入れる。

```ts id="vokfj5"
projectState.addListener((projects: any[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
});
```

そして `renderProjects()` で画面に表示する。

## `ProjectState` の役割

`ProjectState` は、プロジェクトのデータを管理するクラス。

今のコードでは、2つの配列を持っている。

```ts id="j4h2i7"
private listeners: Function[] = [];
private projects: any[] = [];
```

---

## `projects` とは何か

```ts id="a47oyo"
private projects: any[] = [];
```

これは、入力されたプロジェクトを保存しておく配列。

フォームから入力された、

```ts id="sjtztd"
title
description
people
```

を使って、こういうオブジェクトを作る。

```ts id="vq32m8"
const newProject = {
  title: title,
  description: description,
  people: numOfPeople,
};
```

そして、そのプロジェクトを `projects` に追加する。

```ts id="6rbzqn"
this.projects.push(newProject);
```

つまり、`projects` はアプリ内のプロジェクト一覧データを持っている場所。

---

## `listeners` とは何か

```ts id="ldhte1"
private listeners: Function[] = [];
```

これは、あとで実行したい関数を保存しておく配列。

今日の時点では、`ProjectList` が `ProjectState` に listener を登録している。

```ts id="q9b4lc"
projectState.addListener((projects: any[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
});
```

つまり、`listeners` には、

```ts id="8hhyi1"
(projects: any[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
}
```

のような関数が入る。

---

## `addListener()` の役割

```ts id="oqzqn6"
addListener(listenerFn: Function) {
  this.listeners.push(listenerFn);
}
```

これは、外から受け取った関数を `listeners` 配列に登録するメソッド。

つまり、

```ts id="q15m8p"
projectState.addListener(関数);
```

とすると、その関数が `listeners` に保存される。

あとでプロジェクトが追加されたときに、その関数を実行する。

---

## `addProject()` の役割

```ts id="hukmhm"
addProject(title: string, description: string, numOfPeople: number) {
  const newProject = {
    title: title,
    description: description,
    people: numOfPeople,
  };

  this.projects.push(newProject);

  for (const listenerFn of this.listeners) {
    listenerFn(this.projects.slice());
  }

  console.log(this.projects);
}
```

`addProject()` は、入力された値を使って新しいプロジェクトを作る。

そのあと、`projects` 配列に追加する。

```ts id="k8bzeu"
this.projects.push(newProject);
```

その後、登録されている listener をすべて実行する。

```ts id="mdc05p"
for (const listenerFn of this.listeners) {
  listenerFn(this.projects.slice());
}
```

これによって、`ProjectState` にプロジェクトが追加されたことを `ProjectList` に知らせることができる。

---

## `this.projects.slice()` の意味

```ts id="kyg8jh"
listenerFn(this.projects.slice());
```

`slice()` は配列のコピーを作る。

つまり、`this.projects` 本体ではなく、コピーを listener に渡している。

```ts id="nzozq6"
this.projects
```

をそのまま渡すと、外側から元の配列を直接変更される可能性がある。

そのため、

```ts id="kxb679"
this.projects.slice()
```

でコピーを渡している。

考え方としては、

```ts id="gz7hx7"
本物の projects 配列は ProjectState の中で守る
外に渡すのはコピー
```

ということ。

---

## `ProjectList` の役割

`ProjectList` は、プロジェクト一覧を画面に表示するクラス。

今は2つ作っている。

```ts id="es44fr"
const activePrjList = new ProjectList("active");
const finishedPrjList = new ProjectList("finished");
```

`"active"` の方は「実行中プロジェクト」。

`"finished"` の方は「完了プロジェクト」。

---

## `assignedProjects` とは何か

```ts id="svggc8"
assignedProjects: any[] = [];
```

これは、`ProjectList` が表示するために受け取ったプロジェクト一覧。

`ProjectState` が全体のプロジェクトを管理している。

それに対して、`ProjectList` は表示担当なので、自分が表示するためのプロジェクトを `assignedProjects` に持つ。

今はまだ active / finished の絞り込みはしていないので、両方の `ProjectList` が同じ projects を受け取る。

---

## `projectState.addListener()` の流れ

`ProjectList` の constructor の中で、listener を登録している。

```ts id="s0c8e0"
projectState.addListener((projects: any[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
});
```

これは、

```ts id="y4lq6y"
ProjectState にプロジェクトが追加されたら、この関数を実行してね
```

という登録。

プロジェクトが追加されると、`ProjectState` 側でこの関数が呼ばれる。

```ts id="lngdnz"
listenerFn(this.projects.slice());
```

そして、`projects` が渡ってくる。

渡ってきた `projects` を、`ProjectList` 側の `assignedProjects` に入れる。

```ts id="dg9lf3"
this.assignedProjects = projects;
```

そのあと、画面表示のために `renderProjects()` を呼ぶ。

```ts id="z0rf80"
this.renderProjects();
```

## `renderProjects()` の役割

```ts id="z4l46m"
private renderProjects() {
  const listEl = document.getElementById(
    `${this.type}-projects-list`,
  )! as HTMLUListElement;

  listEl.innerHTML = "";

  for (const prjItem of this.assignedProjects) {
    const listItem = document.createElement("li");
    listItem.textContent = prjItem.title;
    listEl.appendChild(listItem);
  }
}
```

`renderProjects()` は、実際にプロジェクトを画面に表示するメソッド。

まず、表示先の `ul` を取得する。

```ts id="myqfcq"
const listEl = document.getElementById(
  `${this.type}-projects-list`,
)! as HTMLUListElement;
```

そのあと、`ul` の中身を一度空にする。

```ts id="l9nzki"
listEl.innerHTML = "";
```

これは、同じプロジェクトが重複表示されないようにするため。

そのあと、`assignedProjects` を1つずつ取り出す。

```ts id="grs4jq"
for (const prjItem of this.assignedProjects) {
```

そして、`li` を作る。

```ts id="gh99qd"
const listItem = document.createElement("li");
```

`li` の文字をプロジェクトのタイトルにする。

```ts id="qjjh0v"
listItem.textContent = prjItem.title;
```

最後に、`ul` に追加する。

```ts id="id8k5o"
listEl.appendChild(listItem);
```

これで、入力したプロジェクト名がリストに表示される。

---

## なぜ `listEl.innerHTML = ""` が必要か

`renderProjects()` は、プロジェクトが追加されるたびに呼ばれる。

もし `listEl.innerHTML = ""` がないと、毎回同じプロジェクトを追加し直すことになる。

たとえば、1回目に `aaaaa` を追加すると、

```ts id="goi9yn"
- aaaaa
```

になる。

2回目に `bbbbb` を追加すると、`assignedProjects` は、

```ts id="kwl6cr"
[
  { title: "aaaaa", description: "...", people: 1 },
  { title: "bbbbb", description: "...", people: 2 }
]
```

になる。

この2件をもう一度全部 `appendChild` するため、空にしていないと、

```ts id="prk26i"
- aaaaa
- aaaaa
- bbbbb
```

のように重複してしまう。

だから最初に、

```ts id="r32trv"
listEl.innerHTML = "";
```

でリストを空にしてから、現在の `assignedProjects` を描画し直している。

## 今日の到達点

今日の時点で、以下の流れまではコードとして実装できた。

```ts id="pe69d0"

↓
projectState.addProject(title, desc, people)

ProjectState の projects に追加
↓
```

つまり、入力フォームから画面表示までの流れが一応つながった。
