# TypeScript 学習ログ：`textContent` と `prjItem.title` の理解

## 今日のテーマ

今日は、TypeScript のプロジェクト管理アプリ課題で、プロジェクト一覧を画面に表示する処理を復習した。

特に、次の2行の意味を確認した。

```ts
listItem.textContent = prjItem.title;
listEl.appendChild(listItem);
```

---

## 今日理解したこと

### 1. `createElement("li")` は空の `<li>` を作るだけ

まず、次のコードで `<li>` 要素を作る。

```ts
const listItem = document.createElement("li");
```

この時点では、HTML のイメージはこうなる。

```html
<li></li>
```

まだ中身の文字は入っていない。

つまり、`createElement("li")` は **空の部品を作っているだけ**。

---

### 2. `textContent` は画面に表示する文字を入れる場所

次に、このコードで `<li>` の中に文字を入れる。

```ts
listItem.textContent = prjItem.title;
```

たとえば、`prjItem.title` が `"買い物アプリ"` だった場合、HTML のイメージはこうなる。

```html
<li>買い物アプリ</li>
```

つまり、`textContent` は、

```txt
HTML要素の中に表示する文字
```

を入れるためのプロパティ。

---

### 3. `appendChild` で画面の `<ul>` に追加する

次に、このコードで作った `<li>` を `<ul>` の中に追加する。

```ts
listEl.appendChild(listItem);
```

たとえば、もともと HTML がこうだったとする。

```html
<ul id="active-projects-list"></ul>
```

そこに `listItem` を追加すると、イメージはこうなる。

```html
<ul id="active-projects-list">
  <li>買い物アプリ</li>
</ul>
```

つまり、`appendChild` は、

```txt
作った要素を、実際のHTMLの中に追加する
```

ための処理。

---

## 今日の重要ポイント

この2行は、次のように読めばよい。

```ts
listItem.textContent = prjItem.title;
listEl.appendChild(listItem);
```

日本語で言うと、

```txt
li にプロジェクトのタイトルを入れる
その li を ul に追加する
```

という意味。

もし `textContent` を書かなければ、空の `<li>` だけが追加される。

```ts
const listItem = document.createElement("li");
listEl.appendChild(listItem);
```

この場合、HTML のイメージはこうなる。

```html
<ul>
  <li></li>
</ul>
```

`li` は存在するが、中身が空なので画面にはほとんど何も表示されない。

---

## `prjItem.title` の `title` はどこから来るのか

最初は、次のコードがあるから `prjItem.title` になるのかと思った。

```ts
this.titleInputElement = this.element.querySelector(
  "#title",
) as HTMLInputElement;
```

これはかなり近いが、正確には少し違う。

このコードは、

```txt
HTML の id="title" の入力欄を取得している
```

だけ。

入力欄の中身を取り出すには、次のように `.value` を使う。

```ts
const enteredTitle = this.titleInputElement.value;
```

ここで、ユーザーが入力したタイトル文字列を取得している。

---

## 入力欄から `prjItem.title` までの流れ

全体の流れはこう。

```txt
<input id="title"> に入力する
        ↓
this.titleInputElement.value で値を取り出す
        ↓
enteredTitle に入る
        ↓
projectState.addProject(...) に渡す
        ↓
newProject の title プロパティに保存される
        ↓
prjItem.title で取り出す
        ↓
listItem.textContent に入れて画面に表示する
```

つまり、`prjItem.title` の `title` は、HTML の `id="title"` を直接見に行っているわけではない。

一度、次のようなオブジェクトとして保存されている。

```ts
const newProject = {
  id: Math.random().toString(),
  title: title,
  description: description,
  people: numOfPeople,
};
```

この結果、プロジェクトは次のような形になる。

```ts
{
  id: "0.12345",
  title: "買い物アプリ",
  description: "買い物を管理するアプリ",
  people: 3
}
```

だから、あとで次のように書ける。

```ts
prjItem.title
```

これは、

```txt
今取り出しているプロジェクトの title プロパティ
```

を意味する。

---

## 今日の自分の理解

今日の理解は、次のようにまとめられる。

```txt
#title は HTML の入力欄
titleInputElement.value は入力された文字
newProject.title は保存されたプロジェクト名
prjItem.title は保存済みデータから取り出したタイトル
textContent は画面に表示する文字
appendChild は画面のHTMLに追加する処理
```

## 今日のコードの読み方

```ts
for (const prjItem of this.assignedProjects) {
  const listItem = document.createElement("li");
  listItem.textContent = prjItem.title;
  listEl.appendChild(listItem);
}
```

このコードは、次のように読む。

```txt
assignedProjects の中からプロジェクトを1つずつ取り出す
        ↓
li を作る
        ↓
その li にプロジェクトのタイトルを入れる
        ↓
ul に追加して画面に表示する
```
