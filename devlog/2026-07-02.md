# 学習ログ：Project クラスと status によるプロジェクトの振り分け

## 今日の学習内容

今日は、TypeScript のプロジェクト管理アプリで、追加したプロジェクトが「実行中プロジェクト」と「完了プロジェクト」の両方に表示されてしまう問題について確認した。

原因は、プロジェクトを追加したときに、各プロジェクトに `status` が設定されていなかったことだった。

そのため、`ProjectList` 側で `status` を使って絞り込みをしても、正しく判定できなかった。

---

## 今日の修正ポイント

これまで `addProject()` では、普通のオブジェクトとしてプロジェクトを作成していた。

```ts
const newProject = {
  title: title,
  description: description,
  people: numOfPeople,
};
```

しかし、これだと `status` が存在しない。

そのため、`Project` クラスを使ってインスタンスを作成する形に修正した。

```ts
const newProject = new Project(
  Math.random().toString(),
  title,
  description,
  numOfPeople,
  ProjectStatus.Active,
);
```

これにより、新しく追加されたプロジェクトには最初から `ProjectStatus.Active` が設定されるようになった。

---

## ProjectStatus enum

プロジェクトの状態を管理するために、`enum` を使用した。

```ts
enum ProjectStatus {
  Active,
  Finished,
}
```

`Active` は実行中、`Finished` は完了を表す。

内部的には、`Active` は `0`、`Finished` は `1` として扱われる。

---

## Project クラス

プロジェクトのデータ構造をクラスとして定義した。

```ts
class Project {
  constructor(
    public id: string,
    public title: string,
    public description: string,
    public people: number,
    public status: ProjectStatus,
  ) {}
}
```

このクラスでは、プロジェクトに必要な情報として以下を持たせている。

* `id`
* `title`
* `description`
* `people`
* `status`

`constructor` の引数に `public` を付けることで、プロパティ宣言と代入を同時に行っている。

---

## ProjectState の修正

`projects` 配列には `Project` クラスで作ったインスタンスを入れるため、型を `Project[]` にした。

```ts
class ProjectState {
  private listeners: Function[] = [];
  private projects: Project[] = [];

  addListener(listenerFn: Function) {
    this.listeners.push(listenerFn);
  }

  addProject(title: string, description: string, numOfPeople: number) {
    const newProject = new Project(
      Math.random().toString(),
      title,
      description,
      numOfPeople,
      ProjectStatus.Active,
    );

    this.projects.push(newProject);

    for (const listenerFn of this.listeners) {
      listenerFn(this.projects.slice());
    }

    console.log(this.projects);
  }
}
```

---

## addProject() の流れ

`addProject()` の流れは以下の通り。

```txt
フォームから title, description, people を受け取る
↓
new Project(...) で新しい Project インスタンスを作る
↓
status は最初に ProjectStatus.Active にする
↓
this.projects に追加する
↓
listeners に登録された関数をすべて実行する
↓
ProjectList 側に projects 配列のコピーを渡す
```

---

## ProjectList 側の絞り込み

`ProjectList` では、`projectState.addListener()` の中でプロジェクトを受け取る。

```ts
projectState.addListener((projects: Project[]) => {
  const relevantProjects = projects.filter((prj) => {
    if (this.type === "active") {
      return prj.status === ProjectStatus.Active;
    }
    return prj.status === ProjectStatus.Finished;
  });

  this.assignedProjects = relevantProjects;
  this.renderProjects();
});
```

ここでは、`this.type` が `"active"` か `"finished"` かによって、表示するプロジェクトを分けている。

`this.type === "active"` の場合は、`status` が `ProjectStatus.Active` のものだけを残す。

```ts
return prj.status === ProjectStatus.Active;
```

それ以外、つまり `"finished"` の場合は、`status` が `ProjectStatus.Finished` のものだけを残す。

```ts
return prj.status === ProjectStatus.Finished;
```

---

## assignedProjects に入るもの

`this.assignedProjects` には、すべてのプロジェクトではなく、絞り込まれたプロジェクトだけが入る。

```ts
this.assignedProjects = relevantProjects;
```

たとえば、実行中リストの場合は、`Active` のプロジェクトだけが入る。

完了リストの場合は、`Finished` のプロジェクトだけが入る。

---

## renderProjects() の役割

`renderProjects()` は、`assignedProjects` に入っているプロジェクトを画面に表示する役割。

```ts
private renderProjects() {
  const listEl = document.getElementById(
    `${this.type}-projects-list`,
  )! as HTMLUListElement;

  listEl.innerHTML = "";

  for (const prjItem of this.assignedProjects) {
    const listItem = document.createElement("li");
    listItem.textContent = prjItem.title;
    listEl.appendChild(listItem);
  }
}
```

ここでは、`this.assignedProjects` の中身を `for...of` で1つずつ取り出している。

取り出した1件のプロジェクトが `prjItem`。

```ts
for (const prjItem of this.assignedProjects)
```

`prjItem.title` を使って、プロジェクトのタイトルを `<li>` に表示している。

```ts
listItem.textContent = prjItem.title;
```

---

## 今日理解したこと

今日理解したことは、`renderProjects()` が直接「実行中」や「完了」を判断しているわけではないということ。

実際には、`addListener()` の中で `filter()` を使い、`assignedProjects` に入れる前に表示対象を絞り込んでいる。

そのため、役割は以下のように分かれている。

```txt
ProjectState
  → 全プロジェクトを管理する

addListener()
  → ProjectList に変更を通知する

ProjectList
  → active / finished に応じてプロジェクトを絞り込む

assignedProjects
  → 画面に表示するプロジェクトだけを保存する

renderProjects()
  → assignedProjects の中身を画面に表示する
```

---

## 今日の重要ポイント

今日の一番大事なポイントは、以下の流れ。

```txt
new Project(..., ProjectStatus.Active)
↓
projects 配列に追加
↓
listenerFn(this.projects.slice()) で通知
↓
ProjectList 側で filter()
↓
active / finished に応じて assignedProjects に入れる
↓
renderProjects() で表示
```

これにより、プロジェクトを追加したときに、実行中プロジェクトと完了プロジェクトの両方に表示される問題を修正できる。
