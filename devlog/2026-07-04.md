# 学習ログ：ProjectState / ProjectList / private / listeners の整理

## 今日のテーマ

今日は TypeScript のプロジェクト管理アプリで、`ProjectState` と `ProjectList` の役割の違いを整理した。

特に以下の点を確認した。

* `ProjectState` の `projects` がなぜ本体データなのか
* `listeners` はなぜ本体データではなく通知用なのか
* `new Project()` と `new ProjectState()` の違い
* `private` が付いていても `addListener()` を呼べる理由
* `listeners` に関数が入る仕組み

---

## 今日確認したコード

```ts
class ProjectState {
  private listeners: Function[] = [];
  private projects: Project[] = [];

  addListener(listenerFn: Function) {
    this.listeners.push(listenerFn);
  }

  addProject(title: string, description: string, people: number) {
    const newProject = new Project(
      Math.random().toString(),
      title,
      description,
      people,
      ProjectStatus.Active
    );

    this.projects.push(newProject);

    for (const listenerFn of this.listeners) {
      listenerFn(this.projects.slice());
    }
  }
}
```

---

## ProjectState の役割

`ProjectState` は、アプリ全体のプロジェクトデータを管理するクラス。

```ts
private projects: Project[] = [];
```

この `projects` は、ユーザーが入力して作成されたプロジェクトを保存する場所。

つまり、アプリにとっての本体データ。

```txt
ProjectState
  └─ projects ← アプリ全体の本体データ
```

---

## ProjectList の役割

`ProjectList` は、画面にプロジェクトを表示するためのクラス。

`ProjectState` が持っている本体データを受け取って、自分の表示用データに入れる。

```ts
projectState.addListener((projects: Project[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
});
```

ここでは、`ProjectState` から渡された `projects` を受け取り、`assignedProjects` に入れている。

```txt
ProjectList
  └─ assignedProjects ← 表示用データ
```

---

## projects と listeners の違い

`ProjectState` の中には、次の2つがある。

```ts
private listeners: Function[] = [];
private projects: Project[] = [];
```

どちらも `ProjectState` の中にあるが、役割が違う。

```txt
projects
  = アプリ本体のデータ

listeners
  = データが変わったときに呼ぶ関数リスト
```

---

## projects は本体データ

`projects` には、プロジェクトそのものが入る。

```ts
[
  {
    id: "1",
    title: "勉強",
    description: "TypeScript復習",
    people: 1,
    status: ProjectStatus.Active
  }
]
```

これは、ユーザーが作成したプロジェクトのデータ。

だから `projects` はアプリの本体データ。

---

## listeners は通知用データ

`listeners` には、プロジェクトそのものではなく、関数が入る。

```ts
[
  (projects: Project[]) => {
    this.assignedProjects = projects;
    this.renderProjects();
  }
]
```

これは、

```txt
ProjectState の projects が変わったら、
ProjectList 側の画面を更新するための関数
```

という意味。

つまり `listeners` は本体データではなく、通知の仕組み。

---

## new Project() と new ProjectState() の違い

`new ProjectState()` は、プロジェクト全体を管理する箱を作る。

```ts
const projectState = new ProjectState();
```

これは、アプリ全体で基本的に1回作る。

一方で、`new Project()` はプロジェクト1件分を作る。

```ts
const newProject = new Project(
  Math.random().toString(),
  title,
  description,
  people,
  ProjectStatus.Active
);
```

整理すると、

```txt
new ProjectState()
  = 管理用の箱を作る

new Project()
  = プロジェクト1件を作る
```

そのため、プロジェクトを追加するたびに `new ProjectState()` するのではなく、`ProjectState` の中で `new Project()` を行う。

---

## private の理解

次のコードでは、`private` が付いているのは `listeners` と `projects`。

```ts
class ProjectState {
  private listeners: Function[] = [];
  private projects: Project[] = [];
}
```

これは、外から直接触れないという意味。

```ts
projectState.listeners; // エラー
projectState.projects;  // エラー
```

ただし、`ProjectState` の中からなら使える。

```ts
class ProjectState {
  private projects: Project[] = [];

  addProject(title: string, description: string, people: number) {
    const newProject = new Project(
      Math.random().toString(),
      title,
      description,
      people,
      ProjectStatus.Active
    );

    this.projects.push(newProject);
  }
}
```

`this.projects` は `ProjectState` の中で使っているのでOK。

---

## なぜ projectState.addListener() は使えるのか

`listeners` は `private` なので、外から直接は触れない。

```ts
projectState.listeners.push(...); // エラー
```

しかし、`addListener()` には `private` が付いていない。

```ts
addListener(listenerFn: Function) {
  this.listeners.push(listenerFn);
}
```

そのため、外から呼べる。

```ts
projectState.addListener(...); // OK
```

つまり、

```txt
listeners は private
addListener は public
```

ということ。

外から `listeners` を直接触るのは禁止だが、`addListener()` という公開されたメソッドを通して登録することはできる。

---

## listeners に関数が入る流れ

`ProjectList` 側で、次のように関数を登録する。

```ts
projectState.addListener((projects: Project[]) => {
  this.assignedProjects = projects;
  this.renderProjects();
});
```

`ProjectState` 側では、この関数を `listenerFn` として受け取る。

```ts
addListener(listenerFn: Function) {
  this.listeners.push(listenerFn);
}
```

その結果、`listeners` の中には次のような関数が入る。

```ts
[
  (projects: Project[]) => {
    this.assignedProjects = projects;
    this.renderProjects();
  }
]
```

---

## データ追加から画面更新までの流れ

```txt
1. フォームから入力される

2. ProjectState.addProject() が呼ばれる

3. new Project(...) でプロジェクト1件を作る

4. this.projects.push(newProject)
   → 本体データに追加する

5. listeners に登録されている関数を実行する

6. ProjectList の assignedProjects に projects が入る

7. renderProjects() で画面を描き直す
```

コードではこの部分。

```ts
for (const listenerFn of this.listeners) {
  listenerFn(this.projects.slice());
}
```

これは、`listeners` に登録しておいた関数を順番に実行している。

`this.projects.slice()` を渡すことで、ProjectState の本体データのコピーを ProjectList に渡している。

---

## 今日の理解まとめ

```txt
Project
  = プロジェクト1件のデータ

ProjectState
  = プロジェクト全体を管理する箱

ProjectList
  = 画面に表示する係
```

```txt
projects
  = アプリ本体のデータ

listeners
  = データが変わったときに実行する関数リスト

assignedProjects
  = ProjectList が表示用に持つデータ
```

```txt
private は、付いているメンバーを外から直接使えなくするもの。

private が付いている projects / listeners は外から直接触れない。

ただし、private が付いていない addProject() / addListener() は外から呼べる。
```

---

## 今日つかんだ重要ポイント

`ProjectState` の中に `projects` と `listeners` があるが、どちらも同じ意味のデータではない。

`projects` はアプリで扱う本体データ。

`listeners` は、そのデータが変わったときに画面側へ知らせるための仕組み。

また、`private` はクラス全体を外から使えなくするものではなく、`private` が付いているプロパティやメソッドだけを外から直接使えなくする。
