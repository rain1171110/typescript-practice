## JavaScript と TypeScript の型の違い

JavaScript は実行時に値の型を判断する。

```js
typeof "Max"; // "string"
```

TypeScript は実行前に型をチェックする。

```ts
let userName: string;
userName = "Maximilian";
userName = false; // コンパイルエラー
```

### 学んだこと

- JavaScript: 実行時に型を判断する
- TypeScript: 実行前に型をチェックする
- TypeScript はランタイムでは何もしない

---

## TypeScript の型はコンパイル後に消える

```ts
function add(n1: number, n2: number) {
  return n1 + n2;
}
```

コンパイル後の JavaScript では型情報が消える。

```js
function add(n1, n2) {
  return n1 + n2;
}
```

### 学んだこと

- TypeScript は実行前のチェック役
- 実行中に動いているのは JavaScript
- 型情報はコンパイル後に消える

## 関数の引数に型をつける

```ts
function add(n1: number, n2: number, showResult: boolean, phrase: string) {
  const result = n1 + n2;

  if (showResult) {
    console.log(phrase + result);
  } else {
    return result;
  }
}

const number1 = 5;
const number2 = 2.8;
const printResult = true;
const resultPhrase = "Result:";

add(number1, number2, printResult, resultPhrase);
```

このコードで指定した型:

- `n1`: number
- `n2`: number
- `showResult`: boolean
- `phrase`: string

### 補足

- `const result = n1 + n2;` を先に計算しておくと、意図しない文字列結合を防げる

## 文字列と数値の + の違い

```ts
console.log("Result:" + 5 + 2.8);
```

出力:

```txt
Result:52.8
```

理由は左から順に評価され、最初に文字列結合が始まるため。

```ts
const result = 5 + 2.8;
console.log("Result:" + result);
```

出力:

```txt
Result:7.8
```

## 型推論と型注釈

```ts
const age: number = 29; // 型注釈
const age2 = 29; // 型推論
```

### 学んだこと

- `: number` のように自分で型を書く: 型注釈
- 型を書かず TypeScript に判断させる: 型推論

## オブジェクトの型

```ts
const person = {
  name: "yota",
  age: 30,
};
```

推論される型:

```ts
{
  name: string;
  age: number;
}
```

```ts
console.log(person.name); // OK
// console.log(person.job); // エラー
```

---

## ネストしたオブジェクトの型

```ts
const product = {
  id: "abc1",
  price: 12.99,
  tags: ["great-offer", "hot-and-new"],
  details: {
    title: "Red Carpet",
    description: "A great carpet - almost brand-new!",
  },
};
```

### 学んだこと

- オブジェクト内のオブジェクトも型定義できる
- 配列は `string[]` のように書ける
- ネストした中身まで型推論される

---

## 配列の型

```ts
let favoriteActivities: string[];
favoriteActivities = ["Sports"]; // OK
favoriteActivities = ["Sports", "Cooking"]; // OK
// favoriteActivities = ["Sports", 1]; // エラー
```

---

## for...of と配列の中身の型

```ts
const person = {
  name: "yota",
  age: 30,
  hobbies: ["Sports", "Cooking"],
};

for (const hobby of person.hobbies) {
  console.log(hobby.toUpperCase());
  // hobby.map(); // エラー
}
```

### 学んだこと

- `person.hobbies` は `string[]`
- `hobby` は `string`
- 配列そのものと、取り出した1つの値は型が違う

## GitHub リポジトリ作成と push

発生したエラー:

```txt
error: src refspec main does not match any
```

原因:

- 現在のブランチ名が `master` なのに、`main` を push しようとしていた

対応:

```bash
git branch -M main
git branch
```

確認結果:

```txt
* main
```

## package.json の JSON エラー

発生したエラー:

```txt
npm error code EJSONPARSE
npm error JSON.parse Invalid package.json
```

原因:

- `scripts` 内のプロパティ区切りカンマ不足

誤り:

```json
"scripts": {
	"test": "echo \"Error: no test specified\" && exit 1"
	"start": "lite-server"
}
```

正しい形:

```json
"scripts": {
	"test": "echo \"Error: no test specified\" && exit 1",
	"start": "lite-server"
}
```
